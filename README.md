# itraj.in

Static site for Raj Singh (Shopify, CRO, automation). Plain HTML/CSS/JS, no build step.

- `index.html`, `assets/`: the public site
- `admin/`: password-protected admin (inquiries, projects, reviews, client videos, site numbers)
- Data and contact form: Supabase project `itraj-site` (row-level security on every table)
- Hosting: Vercel (free) from this repo; domain at BigRock
